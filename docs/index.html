Requests as files

One .http file per request. Commit them next to the code, share them with the team.

Environments

-e prod swaps base URLs, headers and secrets. Config files merge from your home folder down to the project.

Smoke tests

-s 201 checks the status, -t "ok" checks the body. Non-zero exit on mismatch, so CI can run it.

Chaining

jsonr run script.js gives you a jsonr() function to pass one response into the next request.

Built for AI agents that should never see your keys.

An agent can run jsonr against real APIs while the API key stays in a file it never reads.

  • Secrets live outside the repo in a JSON file referenced from jsonr-config.json.
  • Every log is scrubbed. Any secret value that shows up in output, including --debug, is replaced with *****.
  • The command is safe to paste. jsonr create-user.http -e prod contains no credential, so it can sit in a prompt, a script or a chat.

Install

curl -fsSL sobanieca.github.io/jsonr/install.sh | bash

Or with Deno: deno install -g -f -r -n jsonr --allow-net --allow-read --allow-write --allow-env=HOME,USERPROFILE jsr:@sobanieca/jsonr. Run jsonr --help to read everything in about five minutes.
